This site has no analytics and no tracking cookies. It saves your light or dark theme choice in your own browser. It's hosted on
GitHub Pages, which keeps standard server logs (see [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)).

I also use a personal Google API app, "Claude Code Workspace MCP," that only I sign in to. Its data stays on my computer and isn't
shared with anyone.
