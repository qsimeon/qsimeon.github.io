This site has no analytics and no tracking cookies. It saves your light or dark theme choice in your own browser. Fonts load from
Google Fonts, so Google sees your IP address when a page loads. The site is hosted on GitHub Pages, which keeps standard server logs
(see [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)).

I also use a personal Google API app, "Claude Code Workspace MCP," that only I sign in to. It lets my AI coding assistant (Claude
Code) read and organize my own Gmail, calendar, Drive files, contacts, and tasks when I ask it to. That data goes to the AI model
provider only to answer my requests, and it isn't sold or shared with anyone else.
