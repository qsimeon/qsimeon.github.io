GrowLab

A scaling law takes compute C and chooses the parameter count N and token count D. Each law assumes that N stays constant for the whole run without arguing for it.

GrowLab asks a different question: given compute C, choose the trajectory N(t). The answer is a whole curve rather than a single number.
